Import moments

Paste a JSON array of moments — each needs name, lat, lng, and start (YYYY-MM-DD). end and note are optional; leave end as null for "still here."

Backup & restore

Your data lives only in this browser, on this device. Download a backup file whenever you add a bunch of moments, then import that file on another device or browser to carry your data over, or to restore it if this browser's storage ever gets cleared.

Manage city list

Add any city here and it'll show up in the autocomplete (when adding/editing a moment) and in the quick-edit chat, forever — saved right in this browser, no code changes needed. You can find a city's latitude/longitude by searching for it on Google Maps and right-clicking the pin.
